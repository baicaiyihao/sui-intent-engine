# Sui Intent Engine 产品文档

## 1. 用户故事

### 目标用户
**角色**: DeFi 用户
**背景**: 用户熟悉 DeFi 操作但希望用自然语言表达交易意图，无需关心底层区块链细节
**需求**: 通过自然语言描述交易目的，系统自动完成意图解析、风险评估、交易预览和执行

### 典型场景
```
用户输入: "我想把 1000 USDC 换成 ETH，当滑点不超过 0.5%，如果 ETH 价格跌到 3000 以下就自动取消"
系统执行: 解析意图 → 风险检查 → PTB 预览 → 用户确认 → Mock 执行
```

---

## 2. MVP 功能范围

### 2.1 意图解析
- 自然语言输入解析为结构化交易参数
- 支持交易对、滑点、止损条件、金额等
- 输出解析结果供用户确认

### 2.2 风险检查
- 滑点风险评估
- 智能合约风险提示
- 资金风险警示
- 交易可行性预检

### 2.3 PTB（Permission Token Builder）预览
- 生成交易权限构建器预览
- 显示交易类型、金额、限制条件
- 预览 Gas 费用估算

### 2.4 用户确认
- 展示完整交易信息
- 用户最终确认或取消
- 拒绝时清理所有临时状态

### 2.5 Mock 执行
- 模拟交易执行流程
- 验证端到端链路
- 记录执行日志供调试

## 3. 功能优先级

### P0 - 必须有（6周计划内完成）
| 功能 | 描述 | 验收标准 |
|------|------|----------|
| 自然语言解析引擎 | 基础 NLP 解析 + MiniMax LLM 调用 | 输入 "swap 1000 USDC to ETH" 能输出结构化参数 |
| 意图结构化输出 | 解析结果标准化 | 包含 action, amount, token_in, token_out, slippage |
| Mock 执行引擎 | 模拟 Sui 交易执行 | 能跑通完整 mock 流程并返回结果 |
| PTB 生成 | 生成 Permission Token | 能生成有效的 PTB 结构 |

### P1 - 重要（6周计划内完成）
| 功能 | 描述 | 验收标准 |
|------|------|----------|
| 风险检查模块 | 基础风险评估 | 识别滑点风险、金额异常 |
| PTB 预览界面 | CLI/Web 预览交易 | 用户能看到完整 PTB 内容 |
| 用户确认流程 | 确认/拒绝交互 | 支持 Yes/No 确认 |
| 日志与错误处理 | 执行日志记录 | 能追踪每步执行状态 |

### P2 - 增强（6周后迭代）
| 功能 | 描述 |
|------|------|
| 高级风险模型 | 多维度风险评分 |
| 实时价格校验 | 交易前价格有效性检查 |
| 历史意图记录 | 存储用户历史交易意图 |
| 多链支持扩展 | 支持更多链的意图解析 |
