# SuiIntent Guardian - 项目计划书

> 让 DeFi 像对话一样简单，保留机构和散户级别的风控

---

## 1. 项目概述

### 1.1 一句话描述

**SuiIntent Guardian** 是一个基于自然语言的 DeFi 交易意图引擎，用户用日常语言描述交易目标，系统解析为 SUI PTB 交易，在执行前进行多维度风险检查，并以人类可读的方式展示预览，确保用户始终掌控交易决策。

### 1.2 解决的问题

| 痛点 | 现状 | 我们的方案 |
|------|------|------------|
| DeFi 门槛高 | 需要理解 LP、AMM、滑点等概念 | 自然语言交互 |
| AI Agent 不透明 | 黑箱决策，用户不敢用 | 人类可读预览 + 确认 |
| 风险不可见 | 下单后才知道亏损 | Guardian 实时检查 |
| 策略无法验证 | 回测数据不公开 | Walrus 存证 |

### 1.3 核心创新

1. **Intent First** - 不是"AI 替你交易"，而是"AI 帮你理解和执行"
2. **Guardian Layer** - 每个交易都经过多维度风险检查
3. **Human in the Loop** - 用户始终有最终确认权
4. **Verifiable** - 策略快照存证 Walrus，可追溯、可验证

## 3. 产品功能

### 3.1 核心功能

#### F1: 自然语言意图解析

**输入示例**：
```
"RSI 低于 30 的时候买入 100 美金 SUI，止损 2%，止盈 6%"
```

**解析输出**：
```json
{
  "action": "buy",
  "asset": "SUI",
  "amount_usd": 100,
  "trigger": {
    "indicator": "RSI",
    "condition": "<",
    "threshold": 30
  },
  "stop_loss_pct": 2,
  "take_profit_pct": 6
}
```

#### F2: Guardian 风险检查

| 风险类别 | 检测指标 | 人类可读提示 |
|----------|----------|--------------|
| 超买/超卖 | RSI > 70 / < 30 | "RSI 处于超买区域，当前 75" |
| 波动性风险 | 布林带位置 | "价格接近布林上轨，波动大" |
| 趋势判断 | MACD 金叉/死叉 | "MACD 形成死叉，短期看跌" |
| 流动性风险 | DeepBook 订单簿深度 | "深度不足，确认滑点 < 0.5%" |

#### F3: PTB 预览与确认

```
┌─────────────────────────────────────────┐
│  📋 交易预览 (待确认)                      │
├─────────────────────────────────────────┤
│  操作：买入 SUI                           │
│  数量：78.5 SUI (≈ $100)               │
│  触发条件：RSI < 30                      │
│  止损：$1.24 (-2%)                      │
│  止盈：$1.35 (+6%)                      │
│                                         │
│  ⚠️ Guardian 风险提示：                   │
│  ✅ RSI 超卖条件满足                      │
│  ✅ MACD 金叉形成                         │
│  ✅ 布林带低位，波动适中                   │
│  ✅ 订单簿深度充足                         │
│                                         │
│  [✅ 确认执行]  [✏️ 修改参数]  [❌ 取消]  │
└─────────────────────────────────────────┘
```

#### F4: DeepBook 执行

- 市价单执行
- 实时价格获取
- 交易结果展示

#### F5: Walrus 存证

- 策略快照上链
- 交易记录存证
- 可验证的完整历史

### 3.2 用户对话流程

